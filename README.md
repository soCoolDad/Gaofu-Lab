# 稿府 Lab · GaoFu Lab

> 本地优先的 AI 小说创作工作台。它首先是一套**写小说的工具**，其次是一套**记住设定、随时快速查看**的资料库，并在此之上融合 AI 辅助创作。

- 稿府 Lab 是一款基于 Electron + React + TypeScript 的桌面应用，内置写作 Agent **「知卷」**。
- 作品、大纲、设定、章节记忆、聊天记录、模型配置、API Key 全部保存在**你本机的本地数据库**中，不上传服务器、不用于训练。

- 平台：macOS · Windows

## 核心能力

### 一、写小说的工具

- **多作品工作区**：作品 / 分卷 / 章节三级结构统一管理，随时切换多本书。
- **正文编辑器**：基于 MDXEditor 的富文本编辑，支持标题、列表、引用、表格、图片、代码块；实时字数统计；写完一键「定稿」。
- **大纲与章节**：书籍总大纲（内置故事背景 / 核心设定 / 主线剧情模板）、分卷大纲、章节大纲逐层衔接。
- **作品写作设置**：单章期待字数、叙述人称、写作风格、禁写清单、写作约束，写作时自动注入 AI。

![主界面：作品工作区](docs/screenshots/01-workspace.png)

### 二、记住设定的工具，快速查看

长篇创作最大的痛点是「写到后面忘了前面」。稿府 Lab 用一套记忆体系把设定和剧情全部记住：

- **9 类结构化设定**：角色、地点、物品、技能、场景、势力、体系、灵感、伏笔（含铺垫 / 出现 / 回收章节），全部支持 Markdown 详情编辑。
- **章节记忆**：章节「定稿」时自动生成本章记忆——剧情接续点、出场角色状态、出场实体、事件、伏笔推进、融入灵感。
- **全书总记忆**：各章记忆自动增量合并为总记忆（角色现状、成长弧、位置轨迹、剧情线、伏笔状态）；每章存一份版本化快照，删除章节可瞬时回滚。
- **编辑页快查面板**：写作时右侧直接查看章节记忆、8 组设定快查、章节 / 分卷大纲，无需翻找。
- **记忆线**：全书章节记忆列表 + 多轨道剧情线可视化（角色 / 场景 / 地点 / 物品 / 技能 / 势力 / 体系 / 灵感各自成轨），点击章节点直接跳转，支持前后章记忆对比。

![设定 / 资料库页](docs/screenshots/03-settings.png)

### 三、融合 AI 辅助创作

- **「知卷」Agent 面板**：对话式总控台。通过 27 个内置工具直接读写你的书籍数据——建作品、写大纲、拆分卷、排章节、写正文、建设定，一站式完成。
- **确认卡机制**：AI 的所有写操作以「待确认卡片」呈现，带类型标签与风险等级；可**编辑后应用**、**重跑**（附原因）、**拒绝**，支持批量应用。
- **自动续跑**：前置结果应用后，AI 自动继续下一步，直到完成你的最初目标。
- **广泛模型兼容**：优先使用原生 function calling，不支持的模型自动降级解析文本工具调用。
- **角色聊天室**：把书中角色拉进同一个房间群聊。每个角色只记得自己的状态与关系（防“上帝视角”），你作为导演发指令，角色依次接龙或同时回复。
- **剧情预演**：导演说戏开局，选定角色按序自动生成剧情片段；可插入旁白 / 事实干预走向，随时把片段压缩成剧情总结（第三群像或第一人称视角），一个房间可开多条预演线对比。
- **工具集**：27 个工具的提示词全部可在线编辑、一键恢复默认。
- **AI 技能**：可导入的提示词技能（如「去 AI 味」humanizer-zh）。侧边栏「辅助资产 → AI 技能」统一管理，支持手动新建、**GitHub 链接导入**（自动识别仓库 / 目录下的 SKILL.md）与 **Zip 压缩包导入**（兼容 Claude Skill 格式）；编辑器选中文字后点「用技能处理」即可一键改写。

![正文写作页（带右侧快查面板）](docs/screenshots/02-writing.png)

### 四、模型管理与消耗统计

- **12 个预置服务商**：DeepSeek、火山方舟（豆包）、通义千问、智谱 GLM、Kimi、百度千帆、腾讯混元、MiniMax、阶跃星辰、零一万物、硅基流动，以及任意 OpenAI 协议兼容的自定义端点；支持从服务商拉取模型列表、连通性测试、配置克隆。
- **API Key 安全存储**：写入前使用系统级加密（Electron safeStorage），明文不落盘。
- **精细计费配置**：输入价 / 输出价 / 缓存命中价、输出上限、上下文上限（超出自动丢弃最早记录）。
- **Token 消耗统计**：每次调用记录缓存命中 / 思考 / 直出拆分、调用次数与费用预估；侧边栏实时显示今日消耗，可按时间 / 模型 / 书籍 / 操作类型筛选。

### 五、本地与隐私

- **完全本地存储**：SQLite（better-sqlite3）+ Drizzle ORM，所有数据落地本机。
- **数据自由**：设置页支持分类清空、一键清空、**数据库导出 / 导入**。
- **应用日志**：记录每次 AI 结果应用的类型、模式与结果，可随时查看。

## 快速开始

### 环境要求

- Node.js 18+
- pnpm / npm / yarn 任意一个包管理器

### 本地运行

```bash
# 安装依赖
npm install

# 启动开发环境（Vite + Electron）
npm run electron:dev
```

### 打包桌面应用

```bash
npm run build
```

打包产物会输出到 `release/` 目录（或按 `electron-builder` 配置存放）。

## 使用说明

1. 首次启动后，打开 **模型管理** 页面添加你的 API Key（可配置多个服务商 / 多个模型，建议先测试连通性）。
2. 新建作品，在 **作品设置** 中补充简介、写作风格、叙述人称、禁写清单等（这些会自动注入 AI 写作上下文）。
3. 打开 **「知卷」面板**，直接说出你的需求，例如“帮我规划一本玄幻小说的大纲和前三章”——AI 会通过工具生成大纲、分卷、章节，并以确认卡形式交你审阅。
4. 在 **正文编辑** 页写作或让 AI 续写；右侧面板可快速查看章节记忆与各类设定。
5. 章节写完后点击 **定稿**，自动生成本章记忆并合并进全书总记忆；在 **记忆线** 页面查看剧情线全景。
6. 随时在 **角色聊天室** 或 **剧情预演** 中试玩剧情走向，把满意的结果沉淀回设定。
7. 在 **设置 -> 「知卷」设置** 中调整上下文深度、携带聊天记录条数、正文写作参考项；在 **设置 -> 数据管理** 中导出 / 导入 / 清空数据。
