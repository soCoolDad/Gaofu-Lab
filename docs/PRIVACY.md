# 稿府 Lab 隐私政策

**最后更新：2026 年 7 月 24 日**

---

## 1. 总则

稿府 Lab（以下简称"本软件"）是一款面向个人作者的本地创作工具。本隐私政策旨在向您说明本软件如何处理您的数据。

本软件的核心原则是：**所有数据保存在您的本机，不上传服务器，不用于训练，不采集任何使用行为或崩溃日志。**

本软件提供调用模型的能力。您可通过「知卷」Agent 发起对话，由您配置的第三方大模型根据对话意图生成内容；Agent 的「Agent（知卷）设置」可调整上下文深度、输出语言、正文写作参考等行为。本软件**不内置任何云端服务**，所有请求均在本机发起、指向您自行配置的模型服务商。

---

## 2. 数据种类与存储位置

### 2.1 本软件在您的本机上存储以下数据

| 数据类别 | 具体内容 | 存储方式 | 存储位置 |
|---------|---------|---------|---------|
| 作品数据 | 书籍、分卷、章节、大纲、正文、设定、标签 | SQLite 数据库 | 本机应用数据目录 |
| 聊天记录 | 您与「知卷」Agent 的对话历史（含上下文快照、应用结果、续跑状态等） | SQLite 数据库 | 本机应用数据目录 |
| 模型配置 | API Key、模型地址、模型名、温度、价格等参数 | SQLite 数据库 | 本机应用数据目录 |
| 工具提示词 | 各工具的提示词覆盖（可选、用户手动配置） | SQLite 数据库 | 本机应用数据目录 |
| Agent（「知卷」）设置 | 上下文深度、输出语言、聊天历史条数、流式超时、正文写作参考勾选等 | SQLite 数据库 | 本机应用数据目录 |
| Token 日志 | 每次调用模型的 token 消耗、费用及请求/响应文本摘要 | SQLite 数据库 | 本机应用数据目录 |
| 记忆数据 | 章节结构化记忆快照、全书总记忆及其版本快照 | SQLite 数据库 | 本机应用数据目录 |
| 缓存数据 | 上下文原文缓存、Prompt 缓存（用于降低重复请求的 token 消耗） | SQLite 数据库 | 本机应用数据目录 |
| 辅助数据 | 时间线片段、实体属性、应用操作日志等 | SQLite 数据库 | 本机应用数据目录 |

### 2.2 API Key 存储说明

您的 API Key 在写入本机 SQLite 数据库前，会先经过操作系统级别的加密（Electron `safeStorage`，底层使用 macOS Keychain、Windows DPAPI 等系统机制）以密文形式存储，**明文不会落盘**。仅在您向对应模型服务商发起请求时，于本机内存中临时解密使用，不会以明文形式写入任何文件。

仍建议您：

- 使用模型服务商提供的仅限必要权限的 API Key
- 定期更换 API Key

### 2.3 不存储的数据

本软件**不存储**以下数据：

- 任何使用行为统计（点击、浏览路径、使用时长等）
- 任何崩溃日志或错误上报
- 任何匿名或非匿名的遥测数据
- 任何设备标识符或用户指纹

## 3. 网络请求

本软件的所有网络请求仅指向您自行配置的第三方模型服务商 API 地址。具体而言：

- 请求内容：您在 Agent 对话中发送的文本上下文和工具调用结果
- 请求目标：仅为您在"模型"页面填写的 API 地址
- 请求频次：仅在您主动发起 Agent 对话时产生

本软件**不会**向任何其他服务器发起请求，包括但不限于：广告服务器、统计服务器、推送服务器。

---

## 4. 第三方共享

本软件**不与任何第三方共享您的数据**。

- 您的作品、大纲、设定、聊天记录等均保存在本机，不通过本软件的服务传输给任何第三方。
- 您发送给模型服务商的请求内容由相应服务商按其自身隐私政策处理，不在本软件的控制范围内。
- 本软件不包含任何第三方 SDK（广告、推送、统计等）。

---

## 5. 数据控制权

您对您的数据拥有完全控制权：

### 5.1 查看与导出

- 所有数据可通过本软件的界面直接查看。
- SQLite 数据库文件位于本机应用数据目录，您可以直接复制导出。

### 5.2 删除与清空

- 本软件"设置 → 数据管理"提供分类清空和一键清空所有数据的功能。
- 清空操作不可恢复，请在操作前确认。

### 5.3 数据迁移

- 您可以通过复制 SQLite 数据库文件在不同设备间迁移数据。
- API Key 等敏感配置建议迁移后重新配置。

## 6. 模型生成内容说明

- 本软件中的内容均由您配置的第三方大模型生成，本软件不参与生成过程。
- 大模型生成的内容可能包含不准确、不完整或与事实不符的信息。
- 您对模型生成内容的使用、发表、传播承担全部责任。

---

## 7. 未成年人保护

- 本软件建议 16 岁以上用户使用。
- 大模型生成内容可能含有不适合未成年人的内容，请勿使用大模型生成违反未成年人保护相关规定的内容。
